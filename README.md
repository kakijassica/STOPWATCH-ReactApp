# ⏱️ STOPWATCH React App

A simple and responsive Stopwatch/Timer web application built using React.js.

This project is used as a practical DevOps project to understand the complete application deployment workflow using GitHub, Jenkins, AWS EC2, and Nginx.

## 🚀 Features

- Session Timer
- Break Timer
- Start / Pause Timer
- Reset Timer
- Increase / Decrease Session Time
- Increase / Decrease Break Time
- Audio notification when the timer completes
- Responsive user interface

🔄 Jenkins CI/CD Pipeline

Jenkins is used to automate the React application build and deployment process.

The pipeline is configured directly in the Jenkins Job → Pipeline → Pipeline Script section. A separate Jenkinsfile is not used in the current setup.

Pipeline Flow

GitHub Repository
       ↓
   Git Checkout
       ↓
   npm ci
       ↓
   npm run build
       ↓
 Deploy build files
       ↓
     Nginx
       ↓
 Live React Application
 
Pipeline Stages

1. Checkout

Jenkins gets the source code from the GitHub master branch.

2. Dependencies

Existing node_modules are removed and project dependencies are installed using:

npm ci

3. Build

The React application is converted into optimized production files using:

npm run build

4. Deploy

The generated files from the build/ directory are copied to the Nginx deployment directory on the AWS EC2 instance.

Nginx is then reloaded to serve the updated application.

☁️ AWS EC2 Deployment

The React application is deployed on an AWS EC2 instance.

Deployment Components

GitHub → Source Code Repository
Jenkins → CI/CD Automation
AWS EC2 → Deployment Server
Nginx → Web Server

The production React build generated by Jenkins is deployed to the Nginx web server on the EC2 instance.

🌐 Nginx

Nginx is used to serve the React production build.

The React application is first converted into static production files:

npm run build

The generated files are then deployed to the Nginx web root.

Current deployment directory:

/var/www/project2/STOPWATCH-ReactApp/

Nginx serves the application from this directory.
